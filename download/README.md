# download/ — ملفات مُولَّدة

هذا المجلد يحتفظ بسكربتات SQL الخاصة بقاعدة بيانات Supabase (شغّلها مرة واحدة
في Supabase → SQL Editor عند إنشاء الجداول أو تحديثها).

لقطات شاشة التحقق (verify-*) لم تعد تُرفع إلى المستودع منذ الجولة 33 —
تُحفظ محلياً خارج المستودع، وتبقى اللقطات القديمة متاحة في تاريخ Git
(حتى الالتزام e84d875) للرجوع إليها عند الحاجة.
